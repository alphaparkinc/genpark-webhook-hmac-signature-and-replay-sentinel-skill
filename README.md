# genpark-webhook-hmac-signature-and-replay-sentinel-skill

Validates provider cryptographic HMAC signatures, enforces microsecond timestamp drift ceilings, and tracks payload nonces to prevent replay attacks across agent integrations.

100% Python Standard Library implementation with zero external dependencies.
